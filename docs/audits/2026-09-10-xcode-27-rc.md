## Final package checks

The DMG contains the app, Applications link and installation guide. License notices and the exact
FFmpeg source archive/build configuration are inside `Contents/Resources/ThirdPartyNotices`.
`DMG_LAYOUT_TEMPLATE` lets the packaging script reuse the previous verified installer's `.DS_Store`
without controlling Finder; the final layout was checked visually after packaging.

The first assembled candidate incorrectly enabled runtime signing flags that differed from the
working Xcode Debug output, preventing its ad-hoc debug dylib from loading. That candidate was
discarded. The final app was re-signed with the **original Debug signing options and entitlements**,
and a new DMG was built. Final filesystem verification, deep/strict app signature verification,
all 102 nested yt-dlp native-library signatures, and launch directly from the final mounted DMG
passed. The compiled debug dylib, FFmpeg, yt-dlp executable and Info.plist match the clean build.
