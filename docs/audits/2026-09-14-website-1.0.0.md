# September 14, 2026 — website and README for 1.0.0

The landing page now gives the actual app screenshot the full content width and presents
download/resume, media capture and file integrity as three static feature summaries. The resume
simulator, tabbed demonstrations, decorative range map, timers, animation handlers and unused
icons were removed. The small facts strip also drops its decorative number labels, which crowded
the values with enlarged text.

Hero and download copy, footer links and the 404 page no longer call the product a beta. The
page identifies macOS 27 support and retains the macOS 26/Apple silicon requirement. The root
README now introduces 1.0.0 and points to the September 14 app audit: 626 tests across 87 suites.
The website README describes the static layout and its remaining navigation/reveal script.

## Verification

- `npm run check`: 19 files, zero errors, warnings or hints.
- `npm run build`: all three static routes built successfully; shared assets were already current.
- Browser checks used the production output served locally, not the development overlay.
- Inspected desktop at 1280 px, tablet at 768 px, and mobile at 390 px and 320 px. Checked light
  and dark appearance, reduced motion, 200% root text size and disabled JavaScript. No horizontal
  overflow was observed at the tested sizes; the enlarged facts-strip values fit their cells.
- All three feature summaries were visible without JavaScript. No product tabs or simulator
  nodes remained. Hero images loaded successfully.
- Mobile navigation opened, followed the Product link and dismissed. Feature/download anchors,
  the Privacy page's return download link and the 404 page's home links were checked.
- The GitHub download button still targets the repository's releases index. Browser console
  inspection reported no warnings or errors.
- Temporary browser emulation was reset after testing. No macOS app source or dependencies
  changed, so the native suites were not rerun for this website-only update.

## Release status

GitHub still listed `v1.0.0-beta.20260910` as the newest published build during this check. The
download note therefore identifies **1.0.0 release preparation** and links to available builds,
instead of pointing at an unpublished version asset. Update that note when 1.0.0 is uploaded.
Local-signing/notarization guidance remains visible and consistent with the root README.

The [app release audit](2026-09-14-release-1.0.0.md) remains the record of native verification
and its signing, Share Extension and bundled-runtime limits. This website check does not resolve
those limits or constitute a binary release. Changes are submitted through `dev` → `main`;
the existing Cloudflare Git integration controls production deployment.
