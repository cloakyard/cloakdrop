# CloakDrop implementation audit — 6 September 2026

This audit produced reliability fixes, broader media compatibility, safer vendor builds, compatible dependency updates, and native macOS interaction improvements. The implementation is substantially better covered, but it is not a certification of every site, network, locale, or failure mode.

**An outstanding dependency issue remains:** the latest official yt-dlp stable, nightly, and master bundles all contain older runtime libraries, including OpenSSL with a newer security patch available. A pinned custom-runtime rebuild proposal is prepared in the dependency report. No new build dependencies were added without the approval required by `AGENTS.md`.

## Native interface improvements

- Clicking a download now transfers keyboard focus from the sidebar into the list. Arrow keys and Select All operate on the visible downloads, and the accent selection matches the focused control.
- Multiple selection displays its count in the inspector. Filters and searches clear selections that are no longer visible.
- Link previews are tied to the complete request, including credentials, cookies, and referrer. Changing a request cancels stale work and clears stale metadata; closing the sheet cancels its task.
- An invalid checksum prevents submission until corrected or cleared, preserving the user's verification intent.
- Audio-only mode has a clean, dedicated presentation instead of text superimposed over disabled video rows. It selects independently downloadable tracks, excluding URI-less in-band audio. Same-language alternatives keep their distinct names. When separate audio mode is available, the video list shows video renditions. Page-extracted formats no longer get an invented DASH badge.
- The inspector uses live media byte/segment progress, shows full selectable failure details, labels segment counts accurately, and does not show a stale transfer speed while paused. Resumability is no longer described as HTTP Range for every protocol.
- Unknown sizes and ETAs no longer produce awkward “of —” and “— left” status lines.
- Progress bars expose percentage values to accessibility and respect Reduce Motion for both the activity sweep and interpolation. Extreme numeric speed/duration values cannot trap the formatters.
- The network preferences explain which transfers use the configured proxy. New localized copy has translations in all ten supported non-English locales.
- Debug builds accept `--verify-dark-appearance` to inspect native dark materials without changing the system preference. Normal launches and release builds are unaffected.

The existing SwiftUI forms, source-list sidebar, system typography, SF Symbols, and native toolbar materials were retained. Scrolling rows use solid content surfaces.

## Release boundaries

The runtime security patch gap should be resolved before declaring all vendor libraries current. TypeScript remains at the newest version supported by Astro Check; forcing its newest major would break the declared dependency contract.

Live recording, expired-media-URL re-resolution, per-resource media authentication and explicit metadata-extractor proxy routing remain separate work. DRM, login/region restrictions and changing site behavior prevent a universal-site guarantee.

Process/manager resume tests and a GUI relaunch transfer passed. Physical power-loss durability, sustained multi-gigabyte soak testing, removable-volume faults and broad real-network/FTPS coverage were not established. No throughput benchmark improvement is claimed.

Visual inspection and accessibility-tree checks improve precision but do not certify every locale, accessibility setting or display size. Release signing/notarization still requires the developer's distribution identity; this machine verifies the ad-hoc Debug build.
