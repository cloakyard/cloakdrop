# CloakDrop website audit — 6 September 2026

The landing page now leads with “Open source. Down to the details.” It retains the established Archivo/JetBrains Mono typography, ocean palette, hairline rules, real app screenshot, and layered illustrations. The normal main view has approximately 422 words. Long engineering explanations and repeated feature diagrams were replaced by three short product chapters, a compact craft/privacy band, and installation guidance.

## Content and release accuracy

- Describes resume for supported transfers, supported media pages, available subtitles/checksums, and the DRM exclusion. It does not claim every site works or promise a benchmark speedup.
- Removed the invented CloakDrop receipt with “SIGNATURE VALID” and “TRUST VERIFIED.” A checksum or local signature result does not establish notarization or publisher trust.
- Retained the GitHub Releases index: the current public builds are prereleases, so GitHub's latest-release redirect is unsuitable.
- The [current public beta](https://github.com/cloakyard/cloakdrop/releases/tag/v1.0.0-beta.20260823) is older than the source changes. The page explicitly says published betas can lag behind current source.
- A short note below the installation steps explains the locally signed, non-notarized beta, paid Apple Developer Program membership, and willingness to consider notarization if demand grows.
- Installation follows [Apple's current guidance](https://support.apple.com/en-us/102445): download the official DMG, drag the app into Applications, attempt to open it, then use Privacy & Security → Open Anyway and confirm Open if the user trusts the download. The bundled DMG ReadMe was brought into sync. [Developer ID](https://developer.apple.com/developer-id/) is the prerequisite for Apple's notarization workflow.
- The full privacy policy still renders from the repository's PRIVACY.md. The 404 page and site README were updated to match the shorter navigation.

## Interaction and accessibility changes

- Finite, staggered range arrival; a user-started relaunch illustration; a gently arriving layered media card; and a short finishing sequence. No looping decorative animation or animation-triggered network requests.
- Replay resets bars before beginning, preventing backward movement from the previous completed state. Reset, tab changes, and hiding the page cancel the illustration.
- Tab buttons support arrows, Home/End, selection state, and focus. Desktop panels retain their height when switching.
- Reduced motion cancels active decorative animation and presents the illustration's completed result immediately.
- Progressive reveals never leave persistent hidden styles behind. With JavaScript disabled, all three product chapters remain readable and the inactive tab strip is hidden.
- Enlarged text can wrap in the header and buttons; narrow containers adapt the spec strip and product tabs. The mobile navigation popover scrolls within short viewports.
- Dark-mode primary buttons use dark text on the brighter ocean background. Main copy is at least 16px and regular labels/actions are generally at least 14px; smaller decorative diagram indices remain nonessential.
