# v1.0.0 RC 2 — Build 20261030

RC2 fixes incomplete media output, adds a compatible MP4 choice to pasted video
links and built-in browser captures, and adds **Buy me a coffee** to About.
This is an optimized Apple silicon Release build made with Xcode 27.1 (27A9275)
and the macOS 27.0 SDK, following RC1.

**Requires:** Apple silicon and macOS 26 or later. About reports **1.0.0 (20261030)**.

## What changed

- Fixed fragmented YouTube video timing that could produce an incomplete-looking
  file. Failed packaging retains staging instead of publishing a partial success.
- Added **MP4 (compatible)** and **Original quality** choices for supported pasted
  pages and browser captures. MP4 selects available H.264/AAC source streams and
  preserves them without re-encoding. Original quality may still produce MKV;
  arbitrary MKV-to-MP4 transcoding is not included.
- Fixed HLS MPEG-TS packet loss, audio-only output naming/containers and audio
  group selection. Compatible HLS variants can offer MP4 when their codec metadata
  establishes compatibility; actual output is validated before publication.
- Added **Buy me a coffee** in About, opening
  [Sumit's Ko-fi page](https://ko-fi.com/sumitsahoo21). The label is translated into
  all ten supported non-English languages.
- Updated the bundled extractor to **yt-dlp 2026.10.26**. **FFmpeg 9.0.2** now retains
  its native AAC decoder for MPEG-TS probing, with networking and all encoders
  disabled. **GRDB 7.11.1** remains current in the recorded dependency review.
  Website dependency/source updates since RC1 are included in the tag; website
  deployment is separate from this native installer.

## Verification

- Fresh arm64 Debug and optimized Release builds pass. Strict SwiftLint reports
  zero violations in 178 files; localization validates 502 strings × ten languages.
- The optimized core run reports **650 tests across 90 suites: 649 executed and
  passed, one opt-in live-site test skipped**. That live test separately passed
  six media cases on October 29.
- Multi-site checks cover YouTube MP4/MKV/audio, Dailymotion HLS MP4/MKV and
  SoundCloud audio. Full decoding and expected packet counts pass. Pasted YouTube,
  browser YouTube/Dailymotion and pasted SoundCloud native workflows were checked.
  Vimeo's protected sample was rejected without publishing a completed file;
  a second sample returned HTTP 401. These are access limits, not successful
  Vimeo download coverage. See the [multi-site evidence](https://github.com/cloakyard/cloakdrop/blob/v1.0.0-rc.2/docs/audits/2026-10-29-multisite.md).
- The exact RC2 app installed from this DMG freshly downloaded the reported
  YouTube clip as a complete **44.489433-second H.264/AAC MP4**, preserving all
  **1,333 video / 1,916 audio packets**. Full decoding and the known-good SHA-256 pass.
- About was inspected in light/dark appearance and its support link opened the
  requested Ko-fi URL. DMG verification, strict nested signatures, 126 relative
  runtime links and all 295 packaged/installed app file/link comparisons pass.

## Install

Installer: **CloakDrop-v1.0.0-rc.2.dmg** (48,626,482 bytes).

1. Download the DMG from this release, open it and drag CloakDrop to Applications,
   replacing the previous app.
2. Open CloakDrop from Applications. If macOS blocks this locally signed RC, use
   **System Settings → Privacy & Security → Open Anyway** for the trusted official
   copy. See [Apple's guidance](https://support.apple.com/en-us/102445).
3. Eject the installer. Existing app data and downloads can remain in place.

Verify with:

```bash
shasum -a 256 ~/Downloads/CloakDrop-v1.0.0-rc.2.dmg
```

Expected SHA-256:

```text
f9b832c9b3f42cc1f12040cc87f20960588d8fe1c48775a13d519c4df45df933
```

`SHA256SUMS.txt` is also attached. The app includes third-party notices and the
complete pinned FFmpeg source archive, configuration and build script.

## Candidate limitations

- **Ad-hoc signed; not Developer ID signed or notarized**, matching RC1. Sandbox
  and hardened runtime remain enabled. Clean-Mac Gatekeeper and App Group/Share
  Extension distribution handoff remain unverified.
- The approved official yt-dlp bundle retains older frozen Python/OpenSSL/SQLite
  patches. Updating yt-dlp does not update every frozen library to its latest
  version; see the [dependency audit](https://github.com/cloakyard/cloakdrop/blob/v1.0.0-rc.2/docs/audits/2026-10-29-youtube.md).
- Provider availability, authentication, region, expired URLs and protected
  streams can still prevent downloads. No universal site guarantee, physical
  power-loss certification or fresh macOS 26 runtime validation is claimed.
