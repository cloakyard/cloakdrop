# v1.0.0 RC 3 — Build 20261118.2

RC 3 adds signed updates in About, queue repair and priority controls, destination moves for unfinished downloads, playlist import, and refinements to the native browser and download controls. The Air installer uses the Cloakyard family mark. Users of RC 2 or earlier should install this DMG once to enable in-app updates.

**Requires Apple silicon and macOS 26 or later.** Built with Xcode 27.2 (27B52) on macOS 27.2.1.

## Install and update

1. Download **CloakDrop-v1.0.0-rc.3.dmg** from this release. The SHA-256 hashes of the DMG and Sparkle ZIP are in **SHA256SUMS.txt**.
2. Open the DMG, drag **CloakDrop** to **Applications**, eject the disk and launch the installed app. This prerelease is ad-hoc signed and unnotarized. Review [Apple’s opening guidance](https://support.apple.com/en-us/102445) if first launch is blocked.
3. Open **Settings → About → Check for Updates**. Automatic checks and downloads are off by default. Sparkle verifies the signed website feed and the update ZIP served by GitHub.

## Dependencies and known limits

The release uses Sparkle 2.10.1, GRDB 7.12.0, FFmpeg 9.0.2 and the official yt-dlp 2026.10.26. By maintainer choice, this RC ships the upstream yt-dlp runtime intact. Its older components include Python 3.14.7, OpenSSL 3.5.7, SQLite 3.50.4, websockets 17.3 and pycryptodomex 3.24.1. Provisioned Share Extension handoff and clean macOS 26 acceptance remain open.
