# v1.0.0 RC 1 — Build 20261019

A fresh, optimized Apple silicon **Release** build using **Xcode 27.0 (27A266a)**
and the **macOS 27.0 SDK**, following the September 10 beta. This candidate brings
the 1.0 reliability work and the new Air installer together. Refreshed website and
social-preview sources are included; website deployment is separate.

**Requires:** Apple silicon and macOS 26 or later. The app reports version 1.0.0
(20261019); the candidate identifier is carried by the release and asset name.

## What changed

- A complete Air website and social preview: responsive light/dark layouts,
  accessible navigation and recovery, and a finite horizon animation with static
  fallbacks. The installer now follows the same quiet visual direction.
- Transfer hardening already in the 1.0 source: validated saved ranges and
  progress, safer recovery of moved destination folders, bounded input parsing,
  scoped remembered credentials and recoverable database-startup errors.
- Browser media naming/window lifecycle corrections and aggregate Dock progress
  fixes, with macOS 27 control updates and the existing macOS 26 fallback.
- Latest compatible website dependencies, including Astro 7.4.0 and Wrangler
  4.151.2. Obsolete dependency overrides are removed. TypeScript remains at the
  supported 6.0.3; Astro Check does not yet support TypeScript 7.
- GRDB 7.11.1, FFmpeg 9.0.2 and official yt-dlp 2026.08.19. The FFmpeg helper remains
  network-free and performs local stream copying. yt-dlp resolves metadata and
  media URLs; CloakDrop transfers the selected payload.

## Verification

- **626 tests passed across 87 suites** in the optimized core run, including
  loopback transfers, persistence/resume, validation and actual H.264/AAC muxing.
- Fresh arm64 Debug and Release builds, strict SwiftLint and localization pass.
- Website clean install, valid dependency tree, zero npm audit findings, Astro
  checks/build, Wrangler dry run, **432 layouts and 34 journeys** pass. Horizon
  GPU lifecycle and six fallback profiles pass; reviewed desktop/laptop/phone
  light/dark captures remain in the repository.
- The RC app launched directly from the DMG, showed the correct About build,
  and completed an 8 MiB loopback download with matching in-app and independent
  SHA-256 verification. This is a functional check, not a throughput benchmark.
- DMG verification, strict nested code signatures and all 295 app file/link
  comparisons pass. The Air installer was reviewed in Finder with its real icons.

## Install

Installer: **CloakDrop-v1.0.0-rc.1.dmg** (48,181,551 bytes).

1. Download the DMG from this official release, open it and drag CloakDrop to Applications.
2. Open CloakDrop from Applications. If macOS blocks this locally signed RC, use
   **System Settings → Privacy & Security → Open Anyway** for the trusted copy
   from this repository. See [Apple's guidance](https://support.apple.com/en-us/102445).
3. Eject the installer.

Verify the installer with:

```bash
shasum -a 256 ~/Downloads/CloakDrop-v1.0.0-rc.1.dmg
```

Expected SHA-256:

```text
c363dc38e9cd48ade60b74458f0f3f83c5dd666f60332af274134086556c9471
```

The included Install Guide covers first launch. `SHA256SUMS.txt` is also attached;
the full build manifest is retained with the source audit.

## Candidate limitations

- **Ad-hoc signed; not Developer ID signed or notarized.** Sandbox and hardened
  runtime remain enabled. App Group/Share Extension distribution handoff and
  Gatekeeper behavior on a clean Mac remain unverified. The existing extension
  deep-link fallback is retained.
- **Approved official-bundle exception:** yt-dlp's official stable distribution
  freezes older Python/OpenSSL and other libraries. The maintainer reconfirmed
  retaining that complete bundle for this RC instead of adding a custom runtime
  pipeline. This is not a claim that every frozen library is current; see the
  [dependency audit](https://github.com/cloakyard/cloakdrop/blob/v1.0.0-rc.1/docs/audits/2026-10-19-dependencies.md).
- Physical power-loss recovery, macOS 26 runtime behavior, every authenticated
  provider/proxy/FTP service, full assistive-technology use and physical GPU/power
  acceptance are not certified by these local checks. Existing media boundaries
  in the README still apply.
- Website source is included in this release; its deployment is separate.

The app includes third-party notices and the complete pinned FFmpeg 9.0.2 source
archive/configuration under `Contents/Resources/ThirdPartyNotices`.
