CloakDrop — Install Guide
═════════════════════════

THE APP
  1.  Drag CloakDrop onto the Applications folder in this window.
  2.  Open it from Applications (Launchpad or Spotlight).
      First launch only: if macOS says it "cannot verify the developer",
      right-click the app → Open → Open. This build is signed ad-hoc for
      testing, so Gatekeeper asks once; afterwards it opens normally.

THE BROWSER EXTENSION  (optional — one-click capture from web pages)
  1.  Copy the "Chrome Extension" folder somewhere permanent first
      (e.g. your Documents). Chrome loads an unpacked extension from that
      location on every launch, so don't leave it on this disk image.
  2.  Open Chrome and go to   chrome://extensions
  3.  Turn on "Developer mode" (top-right toggle).
  4.  Click "Load unpacked" and choose the copied "Chrome Extension" folder.
  5.  Make sure CloakDrop has been opened at least once, so the extension
      can hand downloads to it.

PRIVACY
  Everything runs on your Mac — no accounts, no telemetry, no phone-home.
  Full details live in the app under  Settings ▸ Privacy.
